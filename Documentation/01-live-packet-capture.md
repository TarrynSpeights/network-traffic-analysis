# Investigation 1. Live Packet Capture

## Objective

Capture live network traffic using Wireshark and observe real-time communications occurring on the local network.

## Procedure

Wireshark was configured to capture traffic on the active Wi-Fi interface, en0. While the packet capture was running, normal web browsing activity was generated to create a representative sample of network communications.

## Screenshot

![Live Packet Capture](../Screenshots/01-live-packet-capture.png)

## Findings

The live packet capture displayed multiple network protocols communicating across the network. Wireshark identified the source address, destination address, protocol type, packet length, and additional details for each packet.

This capture demonstrated how Wireshark provides real-time visibility into network activity and how packet captures can support network troubleshooting and cybersecurity investigations.
